# EgoAfford project page

Static GitHub Pages site for **EgoAfford: Task-Oriented Affordance Grounding via Egocentric Referring Segmentation**.

## Local preview

The page has no build step. Open `index.html` locally, or serve this directory with any static HTTP server.

## Release checklist

- Replace `static/pdfs/EgoAfford.pdf` with the final public manuscript when available.
- Add the public arXiv, code, and dataset URLs in `index.html` when they are released.
- In GitHub Pages settings, deploy from the repository's default branch and its root directory.
